🎡 Oh no... What should I do?

Instructions

Somebody tells you about a problem or awkward situation.

You should:

  1. React naturally.
  2. Give advice using should / shouldn’t.
  3. Make a personal connection if possible.

🗣️ Speaking Structure

1️⃣ Reaction

Oh no! / That’s embarrassing! / That sounds stressful. / I’d panic. / That’s so awkward.

2️⃣ Advice

You should apologise. / You shouldn’t ignore it. / You should explain the situation. / You shouldn’t overthink it.

3️⃣ Personal Connection

Something similar happened to me once. / I think I would feel really nervous. / Honestly, I’d probably laugh. / I’ve never experienced that, but...
