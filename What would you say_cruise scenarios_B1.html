🎭 What Would You Say?

React naturally to real cruise ship situations 🚢✨

Scenario 1 – Overbooked yoga class

Context
A guest wants to join the yoga class, but the class is fully booked.
You should use
• waiting list
• available spot
• unfortunately
🟣 A2+ Example

Unfortunately, the yoga class is fully booked, but I can add you to the waiting list.

🔵 B1 Example

Unfortunately, the yoga class is fully booked at the moment, but I can add you to the waiting list and check if there’s an available spot later.

Scenario 2 – Lost guest

Context
A guest can’t find Deck 5 and looks confused.
You should use
• main deck
• go with
🟣 A2+ Example

Deck 5 is near the main deck. I can go with you.

🔵 B1 Example

Deck 5 is close to the main deck area. I can go with you and show you the way.

Scenario 3 – Difficult guest

Context
A guest says: “This service is terrible.”
You should use
• sorry
• experience
• solve
🟣 A2+ Example

I’m sorry about your experience. Let me help you.

🔵 B1 Example

I’m really sorry about your experience. Let me see what I can do to help solve the situation.

Scenario 4 – Stressed coworker

Context
A coworker feels stressed and overwhelmed because many guests need help at the same time.
You should use
• deep breath
• handle
• one step at a time
🟣 A2+ Example

Take a deep breath. We can handle this one step at a time.

🔵 B1 Example

Let’s take a deep breath and handle everything one step at a time. We can do this calmly.

Scenario 5 – Guest complaint about noise

Context
A guest says they couldn’t sleep because there was too much noise near their cabin.
You should use
• I understand
• check the situation
• as soon as possible
🟣 A2+ Example

I understand. I’ll check the situation as soon as possible.

🔵 B1 Example

I understand how uncomfortable that must be. I’ll check the situation and report it as soon as possible.

Scenario 6 – Guest wants immediate attention

Context
You are helping one guest, and another guest interrupts because they want help immediately.
You should use
• assisting another guest
• in order
• as soon as I can
🟣 A2+ Example

I’m assisting another guest now. I’ll help you as soon as I can.

🔵 B1 Example

I’m currently assisting another guest, and we need to handle requests in order. I’ll assist you as soon as I can.
